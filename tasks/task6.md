### Redis: поиск и кэширование

Нужно добавить Redis.

Требования ДЗ 5 к переменным окружения `MOVIE_BASE_URL`, `HTTP_ADDR` и `DATABASE_URL` сохраняются. Дополнительно сервис должен читать `REDIS_ADDR` — адрес Redis в формате `host:port`.

Фильмы по-прежнему хранятся в PostgreSQL. Redis используется для:

- хранения обратного индекса для поиска;
- кэширования ответов на поисковые запросы.

Добавить ручку:

- `GET /search?q=...`

Поиск работает так:

1. При старте сервиса после загрузки фильмов в PostgreSQL строится обратный индекс.
2. Индекс хранится в Redis в формате: слово → список/id фильмов.
3. В индекс попадают слова из `title`, `description`, `director`, `actors`, `genres`.
4. При запросе `/search?q=...` сервис ищет подходящие id фильмов в Redis.
5. Сами фильмы по найденным id читаются из PostgreSQL.

Ответы `/search` нужно кэшировать в Redis на 1 час. Если такой же поисковый запрос уже был за последний час, ответ нужно вернуть из кэша.

### Критерии оценивания

6 баллов — После загрузки фильмов в PostgreSQL при старте строится обратный индекс в Redis по всем полям: title, description, director, actors, genres. Ручка GET /search?q=... находит id через Redis и читает фильмы из PostgreSQL. Ответы кэшируются в Redis на 1 час, повторный запрос возвращается из кэша. Конфигурация, включая REDIS_ADDR, читается из окружения по требованиям задания.

5 баллов — Индекс, поиск и кэширование работают, но есть небольшой недочёт: например, срок жизни кэша отличается от 1 часа. Все указанные поля участвуют в поиске, фильмы читаются из PostgreSQL.

4 балла — Поиск через обратный индекс Redis работает, но отсутствует кэширование ответов, индекс не охватывает часть обязательных полей или не строится автоматически при старте.

3 балла — Ручка поиска есть, но Redis используется только для кэша, а поиск выполняется перебором фильмов или SQL-запросом. Либо индекс строится, но найденные id некорректно преобразуются в результаты из PostgreSQL.

0–2 балла — Работа не сдана, код не компилируется или сервис не запускается. Либо поиск не работает, Redis не используется или ручка /search возвращает заглушки.

Отметка за задание снижается при более поздней сдаче задания (1 балл за каждые 2 недели опоздания).
