### Redis: поиск и кэширование

Нужно добавить Redis.

Фильмы по-прежнему хранятся в PostgreSQL. Redis используется для:

- хранения обратного индекса для поиска;
- кэширования ответов на поисковые запросы.

Добавить ручку:

- `GET /search?q=...`

Поиск работает так:

1. При старте сервиса после загрузки фильмов в PostgreSQL строится обратный индекс.
2. Индекс хранится в Redis в формате: слово → список/id фильмов.
3. В индекс попадают слова из `title`, `description`, `director`, `actors`, `genres`.
4. При запросе `/search?q=...` сервис ищет подходящие id фильмов в Redis.
5. Сами фильмы по найденным id читаются из PostgreSQL.

Ответы `/search` нужно кэшировать в Redis на 1 час. Если такой же поисковый запрос уже был за последний час, ответ нужно вернуть из кэша.
